# Task 2: Python Recap Assignment

## Description
A Python program that reads student submission data from a CSV file and generates a summary report in JSON format.

## Setup Instructions

### 1. Activate the virtual environment
```bash
source venv/Scripts/activate
```

### 2. Run the program
```bash
python task_2/src/main.py task_2/data/submissions.csv task_2/output/summary.json
```

## Output
The program prints a summary to the terminal and saves the full report to `task_2/output/summary.json`.
